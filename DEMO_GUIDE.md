# DeFi Risk Radar — two-minute demonstration

Start from the project directory with `.venv\Scripts\python.exe -m streamlit run app.py`.
Public access uses configurable `ETH_RPC_URL`; the default is Ethereum PublicNode.
No key, wallet, transaction or paid API is required. Fetch before presenting; public services can time out or rate-limit.

1. **0:00 — Fetch and establish evidence.** Click **Fetch public data**. In **Sources & evidence**, show the original Ethereum block, hash and retrieval timestamp. Reserve parameters and oracle-source mappings share that block; DefiLlama spot prices have separate observation timestamps and are not Aave oracle answers. A successful fetch saves a validated snapshot; a failed fetch preserves the previous file.
2. **0:20 — Show the graph.** Point out WETH/USDC configured source addresses and the two evidenced oracle-to-source edges. Arrows mean “depends on.” The other edges are modeled. Full evidence is in the expander. **Independent graph inspection** and **Economic scenario** are separate controls: a market-price shock does not imply a feed failure.
3. **0:40 — Set the position.** Enter **4 WETH** collateral and **6,000 USDC** debt. With captured prices WETH $2,494.090576, USDC $0.999723919 and the captured WETH threshold 83%, base equity is $3,978.02 and HF is 1.38. These reference observations are historical; current prices and reserve parameters can differ.
4. **0:55 — WETH −30%.** Choose **WETH market-price shock** and −30%; set assumed 24h probability **10%**, spread **10 bps**, slippage **20 bps**, trading fee **5 bps**, gas **$10**, and notional **$15,974.71** for this reference example (or use current gross collateral value plus debt value). Leave the optional liquidation penalty unchecked. The reference result is stressed HF **0.97**, collateral price loss **$2,992.91**, stressed equity **$985.11**, expected price-only downside **$299.29**, and assumed exit cost **$65.91**. Adequate current inputs produce an illustrative **EXIT** comparison. HF below 1 signals modeled eligibility; liquidation damage is unquantified without a fraction assumption. An archive or unreliable input keeps the actionable result **MONITOR** regardless of this arithmetic. Exit costs are assumptions, not quotes; debt must be repaid or unwound before full withdrawal.
5. **1:20 — USDC exposure direction.** Switch to **USDC market-price shock / depeg**, −10%. WETH collateral stays unchanged; the reference USDC debt loses $599.83 of USD value, improving equity by the same amount. Expected downside is zero; favorable outcomes are reported separately. Switch to +10% to show the opposite exposure. The WETH graph inspection can remain selected without changing either calculation.
6. **1:40 — Oracle outage.** Choose **USDC oracle-source outage**. The graph focuses the corresponding USDC source and shows its affected path; the independent inspection selection is retained. Expected downside is **N/A / Not quantified**, prices are unchanged references, and the decision is **MONITOR**. An outage alone supplies no evidence for an invented price crash or dollar loss.

## Offline fallback

After an error, retry or click **Load saved source snapshot**. The banner must read **HISTORICAL SNAPSHOT / NOT LIVE**, with its original block and retrieval time. Historical arithmetic remains interactive. Loaded archives return **MONITOR / INSUFFICIENT CURRENT DATA**, even if recently saved; loading never refreshes timestamps or verification. The one-hour price/retrieval/block policy and confidence checks still apply. A fresh successful fetch restores current-data assessment when all checks pass.

If no snapshot exists, use **Use illustrative demo**. It uses WETH $2,500, USDC $1 and an assumed 80% threshold: HF 1.33 initially and 0.93 after WETH −30%. It has no verified source evidence and returns MONITOR. Do not describe these as live observations or expect the captured 0.97 result.

Source discovery verifies direct configured mappings at a recorded block, not feed internals, price answers, fallback behavior or outage likelihood. The model excludes account-specific eMode, actual liquidation execution, funding availability and executable exit liquidity. Public-source availability and current market inputs can change the numerical example.
